# music

Synchronized listening app based on [Together](https://github.com/chtnnh/together).

## Original project
The upstream project is maintained by chtnnh. The original Apache-2.0 license and attribution are retained.

## music customization
- Minimal black theme
- One private room for two approved people
- Synchronized YouTube playback
- Room chat
- Shared playlists
- Listening history
- Favourite songs

**Access-control status:** The two-person server-side restriction is not implemented yet. A room code alone is not sufficient to guarantee that only two people can use the app.
